# Ver.3 に向けたメモ

Ver.2 の信用できる探索結果（40分×3回＋まとめ）が出てから、具体的な調整に入る。ここは方針のメモ。

> **2026-11-07：Ver.3 完成。** `src/data/environments/v3.js` に固定した（保存版）。最新の環境は Ver.4（調整中。固定した時点では Ver.3 と同じ中身）。仕上がりの状況は [ver3-status.md](ver3-status.md)。古の巨獣は T4 のまま（ここまでよく暴れたので、そのままで良しとした）。

## 方針（決めたこと）

- **Ver.2 と同じく分けて実装する**（Ver.2 を固定して、Ver.3 を新しい環境として作る。手順は spec.md §12「新しいバージョンを切るとき」）。
- **基本はアッパー調整**（弱いものを強くする。強いものを削るのは最後の手段）。
- **コスト計算を見直す**。とくに「攻撃速度」と「攻撃」の釣り合い。
  - 攻撃速度が速いと、状態異常（毒・麻痺・呪い）をまく回数が増え、定数の攻撃力加算（攻撃+◯の効果）とも相性がよい。シナジーが多く、強くなりやすい。
  - 攻撃が高いことの利点は、防御を抜けることだけ。シナジーが薄く、強くなりにくい。
  - いまの式（spec.md §6）：`攻撃×攻撃速度/40 × (攻撃/40)^0.4`。重い一撃を割高にしているが、速度側の追加の価値（効果の回数・加算との相性）が足りていない可能性。
- **駒作成（自作駒）を、Ver.2 以前と Ver.3 で分ける**。
  - いまは自作駒が全環境で共通（spec.md §12）。本当は Ver.1 と Ver.2 も分ける予定だったが、同じになっている。Ver.1・Ver.2 はそのままでよい。
  - Ver.3 からは別の保存先にする。
- **全体の駒の中身を調整する**。
  - 今夜の探索で弱いと判定された駒を中心に、個性をつけて強化する。
- **ハニカムを強化する**。
  - コストが重い駒の強さが足りないのが原因かもしれない。
  - ほかの原因も調べる。
- **環境の調整に、人間のチェックを何度か入れる**。
  - これまでは自動で調整していた。
  - 人が手を加えると環境が良くなるのか、悪くなるのかを確かめたい。
- **Ver.2 のほかの問題点も洗い出す**。
- **運の要素を少し減らす**。

## Ver.3 を切った（2026-11-07）

Ver.2 は `src/data/environments/v2.js` に固定した。いつものデータファイルが Ver.3。
**コスト（下の表）と、決めた効果は固定**。能力値などの数字は、コストに合わせて調整した（人のテストで変える場所）。

### 仕組みで変えたこと

- **ペンタグラムと3行のボードの麻痺**：攻撃時の効果を受ける相手が同じ割合で2体いるとき、上の行と下の行を**交互に狙う**（`alternateTies`）。
- **戦闘機の「いちばん速い相手」**：麻痺で遅くなっている分も入れた、今の攻撃速度で選ぶ（`fastestNow`）。
- **吸血**（新しい効果、キャラだけ）：攻撃で与えたダメージの割合だけ、チームのHPを回復。
- **攻撃速度の固定値**（隣接効果など）を作れるようにした（魔剣の +0.1）。
- **遺物の新しい効果**：マスの強化（孤高の紋章）、毒の確率アップ（解毒の聖水）。
- **自作駒の保存先**：Ver.3 からは別。Ver.1・Ver.2 は今までどおり共通。
- **ストーリー・ローグライトは Ver.2 のまま**（相手のチームが Ver.2 のコストで組んであるため。Ver.3 の調整が終わったら組み直す）。
- 新しい仕組みはバランス値に項目があるときだけ動く。Ver.1・Ver.2 の対戦結果が変わらないことをテストで確かめている。

### コスト式（決めたこと＋こちらで決めた数字）

- 指数 1.55 → **1.25**、係数 1.35 → 1.662（実力2の駒のコストは同じ）。
- 防御：キャラ 65 → **80**、道具 28 → **35**。最低ダメージ 0.3 → **0.1**。
- **ダメージ倍率 1.2 → 1.35**（最低ダメージを下げた分、ランダムなチームの平均が12秒になったので、10秒前後に戻した）。
- 回復 0.05 → **0.04**（決めたときは 0.025。下の「調整の経過」1回目で、回復を積むと戦闘が長引いてさらに得をすることが分かったので上げた）。道具の攻撃時の効果 3 → **3.6**。定期付与の毒 1.2 → **0.7**（攻撃時の毒1回と同じ値段）。
- 全体効果の人数 8 → **9**（預言者などが割安だったため）。
- **防御を上げる効果は、前線の数で数える**：キャラの隣接は1体、道具の隣接は1.5体（王冠）、行は1体（聖騎士・呪術師）、全体は3体（結界石）。
- **道具の行効果は2体で数える**（道具がその行の1マスを使う。戦太鼓）。
- **麻痺の対象の重み**：前線 1 → **0.6**（ゴーレム）。ほかは同じ。
- **吸血**：割合 × 攻撃 × 攻撃速度 × 0.036（回復0.04 × ダメージ倍率1.2 × 防御で残る割合の想定0.75）。
- **ボードのコスト上限**：ペンタグラム 46 → **51**、スクエア 52 → **53**、ハニカム 58 → **55**（指数を下げるとハニカムの実力の合計が上がるので、合計をそろえた。そのあと探索で微調整）。
- **魔導シナジーの毒の上乗せ**：1 / 1.5 / 2 / 2.5 → **0.5 / 1 / 1.5 / 2**（安い毒の駒を並べると、攻撃1回ごとの上乗せが強すぎた）。
- **攻撃速度の固定値**：同じ値の割合の1.5倍に数える（遅く重い駒ほど得をするため）。

## Ver.3 の調べもの（2026-11-07、データの数字はまだ変えていない）

### 麻痺を 0.3 → 0.5 に戻したら（`node tools/search.js --env v3 --set paralyzeFactor=0.5`、結果は tools/search-out/v3-p05）

- 探索し直した均衡：**ハニカム 93%**・ペンタグラム 7%・スクエア 0%（0.3 では 35% / 43% / 23%）。
- 型：魔人＋王冠・魔剣・戦闘機（約65%）と、修理工房・大魔導士の耐久と毒（約30%）。
- 遺物：孤高の紋章 100%、雷の宝珠 51%（0.3 では 75%）、砂時計 35%、生命の結晶 35%、癒しの泉 31%。雷の宝珠は減るが、代わりに上がるのはハニカム向けの遺物。
- 時間切れが増える：耐久型は 23〜28秒・時間切れ 18〜82%、魔人の型も時間切れ 9〜18%。
- 理由：麻痺は「少ない強い駒で戦うハニカム」を止める役だった。麻痺の値段（paralyzeSec 0.5）は 0.3 のときのままなので、効きめが約3割落ちる（遅くなる分 70% → 50%）のに値段は同じ＝麻痺の駒が割高にもなる。釣り合わせるなら paralyzeSec ≒ 0.36。
- 0.5 に戻すなら、同時にハニカム（王冠・魔人・耐久型）を抑えないと、ハニカム一色になる。

### 強化の値段と実際の効きめ（効果を外したときのチームの実力の減り ÷ 値段）

- 値段の基準：基準キャラ HP400・攻撃45・防御40・速度1。効く人数は 隣接3体（防御は道具1.5・キャラ1）、行3体（道具2・防御1）、全体9体（防御3）。
- 攻撃の強化はどれも割安（ランダムなチームで 1.3〜2.2 倍）。値段の式に「1発の重さ」（atkPow）が入っていないため。攻撃+% が攻撃速度+% より強いのもこのため（王冠 1.2、軍旗 0.83）。
- 割合の強化は受ける駒の「攻撃×速度」に比例。道具はエースの隣に置かれるので、均衡では王冠が値段の 3.5 倍効く。
- HP・防御の強化は値段負け（歯車 0.75、聖鎧 0.6〜0.8、騎士 0.5、竜人 0.7〜0.85、重装兵 0.5）。
- 案：攻撃の強化に1発の重さの分（約1.5倍）を入れる。道具の割合強化（攻撃%・速度%）は効く人数を 3 → 4.5 くらい。HP・防御の割合は下げる。王冠ならコスト5で攻撃・防御+30% くらい。

### 高コストが使われない理由

- コストあたりの実力：コスト3 ≒ 0.55、コスト15 ≒ 0.39。マスに余りがあると「全マスに平らに配る」のが最適（1マスあたり ペンタグラム4.3・スクエア5.9・ハニカム7.9）。
- 高コストが割に合うのはハニカム中央だけ。中央は6マスと隣接するので「エース＋周りの道具」が最強で、効果のない（値段が全部能力値の）魔人が最も合う。
- 将軍・古の巨獣の隣接強化は、隣が道具だと無駄。竜人の全体HP強化は値段負け。
- コスト上限を上げると、まず得をするのはコスト5〜9。高コストには「安い駒を並べてもまねできない効果」（範囲攻撃・状態異常が効かない・道具を強くする など）を付ける方が効く。

### 使われていない駒（v3-c〜e の上位チームでの登場数がほぼ0）

騎士・狂戦士・聖騎士・剣聖・将軍・魔女・預言者・雷術師（候補には出るが均衡0%）・呪術師・炎術師・豹・熊・古の巨獣・砲台・修理ロボ・エルフ・ドワーフ・吸血鬼・竜人。道具は軍旗・歯車・鉄の剣・毒瓶・槍・結界石・呪いの人形・回復薬。遺物は戦の角笛・魔導書。それぞれの原因と特色の案はチャットで出した（強い型への「答え」になる新能力：麻痺を解く・麻痺が効かない・エースの攻撃を下げる・背水・反撃・毒を減らす など）。

## Ver.3 の新能力と値段の手直し（2026-11-07、コミット済み）

- 新しい効果：号令（rally・開始から数秒だけ攻撃/速度+%）・手当て（cure・毒を減らし麻痺を解く）・吸血を配る（lifestealAura）・毒で攻撃+（venomAtk）・道具を磨く（itemAmp）・種族を決めた全体効果（teamBuff の tribe、値段は tribeShare 0.5 倍）。どれも v3 だけ（v2 以前の環境では値段がないので付けられない）。

## コスト式の方針（2026-11-07 決定）

- **攻撃と攻撃速度は分けない**。足し算にすると、遅い大型（雷術師 9→21）や速い小型（毒蛇 3→6〜8）の値段が狂う。代わりに**コスト式の指数を下げ、高コスト駒に価値（効果）を足す**。
  - 指数を下げても、実力2の駒のコストを据え置くと、安い駒はほぼ変わらず、高い駒が下がる（指数1.25で将軍 14→10、魔人 12→9）。ボードの実力の合計は、ハニカムに少し寄る（指数1.25でペンタグラム 23.4・スクエア 24.4・ハニカム 25.3）。実力1前後の道具（軍旗など）はコスト1→2に上がるものが出る。
- **攻撃速度の累進は入れない**。影響範囲が広く、攻撃速度の魅力は残す。
- **防御**：キャラの防御を割る数を 65 → 80。最低ダメージ（minDamage）を 0.3 → 0.1。
  - 試算で守備型が勝ちすぎるなら、「防御を超えたときの値」を調整する。
  - 目指す関係：最低ダメージの手数（毒など）／相手の手薄な前線を抜ける攻撃力／防御貫通でダメージを出す／超火力で高防御に強い、が釣り合う。
  - 防御貫通 = 攻撃する駒の「相手の防御を無いものとして扱う割合」。キャラ自身（エルフ・猪・狂戦士・剣聖・炎術師・砲台）と、隣の道具（槍0.25・魔剣0.3）の合計で、上限100%。防御が高い相手ほど効く。
- **戦闘時間の目安は10秒**（アグロ7秒・ミッドレンジ10秒・ロングレンジ12秒〜）。回復・時間で効く効果は、ミッドレンジ以降で採用できる値段にする。
  - 回復の係数：0.05 → 0.025（回復1/秒 × 10秒 = HP10 = 実力0.025）。
- **道具**（10秒目安）
  - 道具の攻撃時の効果は「隣3体 × 攻撃速度1.2」を標準にする（itemOnHit 3 → 3.6）。毒瓶 3→4、魔剣 4→5、スタンガン 1→2 に上がる。
  - 毒の香炉は、毒瓶と同じ毒量（約2.9/秒）にする。ただし魔導シナジーの毒ボーナスは「付与1回ごと」なので、1秒に3ずつより、0.3秒ごとに1ずつの方が毒瓶に近い。
  - 防御を上げる全体効果は「3体ぶん」で数える（2体なら割高、ペンタグラムの4体ならお得）。結界石は 2→1 前後。
  - 呪いの人形は「2秒ごとに2秒の呪い」。呪いは重ならないので、呪詛師と併用すると価値が落ちる点に注意。ずっと呪い（受けるダメージ+25%）がコスト2前後になるので、強すぎないかを試算で確かめる。

## ペンタグラムと3行のボードの間の麻痺（直す候補）

攻撃は計算行の割合で分かれる（spec.md §2）。一方、攻撃時の効果（麻痺など）は分かれない。割合のいちばん大きい相手1体を「狙う相手」にして、そこに丸ごとかかる。同じ割合なら上の行が選ばれる（`src/engine/battle.js` の攻撃の解決と `pickParalyzeTargets`）。毒と呪いはチーム全体にかかるので、影響を受けるのは麻痺だけ。

- **ペンタグラムが3行のボードを麻痺させるとき**：1行目と2行目は相手の1行目、3行目は相手の2行目、4行目は相手の3行目を狙う。
  - 2行目は相手の2行目を、3行目は相手の3行目を狙わない。
- **3行のボードがペンタグラムを麻痺させるとき**：1行目はペンタグラムの1行目（1体）、2行目はペンタグラムの2行目（5体）、3行目はペンタグラムの4行目（1体）を狙う。
  - **ペンタグラムの3行目（5体）は狙われない**。かかるのは「ランダム」「全員」の麻痺だけ。
  - 3行のボードの電磁塔（行まとめて麻痺）は、1行目か3行目に置くと1体にしかかからない。
- このため、麻痺のやり取りはペンタグラムがかなり有利。Ver.2 の上位にペンタグラムの機械（電磁塔）が来る理由の一つかもしれない。
- 直し方の候補：
  - 麻痺も割合で分ける（例：割合0.5の行それぞれに、半分の秒数をかける）
  - 同じ割合なら、上の行と下の行を交互に狙う
- 定期付与（毒・呪い）の狙いは、いつも相手の計算行1の前線。いまは全体にかかる効果だけなので問題ない。将来、定期付与の麻痺を足すなら同じ点に気をつける。
