# Ver.3 に向けたメモ

Ver.2 の信用できる探索結果（40分×3回＋まとめ）が出てから、具体的な調整に入る。ここは方針のメモ。

## 方針（決めたこと）

- **Ver.2 と同じく分けて実装する**（Ver.2 を固定して、Ver.3 を新しい環境として作る。手順は spec.md §12「新しいバージョンを切るとき」）。
- **基本はアッパー調整**（弱いものを強くする。強いものを削るのは最後の手段）。
- **コスト計算を見直す**。とくに「攻撃速度」と「攻撃」の釣り合い。
  - 攻撃速度が速いと、状態異常（毒・麻痺・呪い）をまく回数が増え、定数の攻撃力加算（攻撃+◯の効果）とも相性がよい。シナジーが多く、強くなりやすい。
  - 攻撃が高いことの利点は、防御を抜けることだけ。シナジーが薄く、強くなりにくい。
  - いまの式（spec.md §6）：`攻撃×攻撃速度/40 × (攻撃/40)^0.4`。重い一撃を割高にしているが、速度側の追加の価値（効果の回数・加算との相性）が足りていない可能性。
- **駒作成（自作駒）を、Ver.2 以前と Ver.3 で分ける**。
  - いまは自作駒が全環境で共通（spec.md §12）。本当は Ver.1 と Ver.2 も分ける予定だったが、同じになっている。Ver.1・Ver.2 はそのままでよい。
  - Ver.3 からは別の保存先にする。
- **全体の駒の中身を調整する**。
  - 今夜の探索で弱いと判定された駒を中心に、個性をつけて強化する。
- **ハニカムを強化する**。
  - コストが重い駒の強さが足りないのが原因かもしれない。
  - ほかの原因も調べる。
- **環境の調整に、人間のチェックを何度か入れる**。
  - これまでは自動で調整していた。
  - 人が手を加えると環境が良くなるのか、悪くなるのかを確かめたい。
- **Ver.2 のほかの問題点も洗い出す**。
- **運の要素を少し減らす**。

## コスト式の方針（2026-11-07 決定。まだ Ver.3 は切らない）

- **攻撃と攻撃速度は分けない**。足し算にすると、遅い大型（雷術師 9→21）や速い小型（毒蛇 3→6〜8）の値段が狂う。代わりに**コスト式の指数を下げ、高コスト駒に価値（効果）を足す**。
  - 指数を下げても、実力2の駒のコストを据え置くと、安い駒はほぼ変わらず、高い駒が下がる（指数1.25で将軍 14→10、魔人 12→9）。ボードの実力の合計は、ハニカムに少し寄る（指数1.25でペンタグラム 23.4・スクエア 24.4・ハニカム 25.3）。実力1前後の道具（軍旗など）はコスト1→2に上がるものが出る。
- **攻撃速度の累進は入れない**。影響範囲が広く、攻撃速度の魅力は残す。
- **防御**：キャラの防御を割る数を 65 → 80。最低ダメージ（minDamage）を 0.3 → 0.1。
  - 試算で守備型が勝ちすぎるなら、「防御を超えたときの値」を調整する。
  - 目指す関係：最低ダメージの手数（毒など）／相手の手薄な前線を抜ける攻撃力／防御貫通でダメージを出す／超火力で高防御に強い、が釣り合う。
  - 防御貫通 = 攻撃する駒の「相手の防御を無いものとして扱う割合」。キャラ自身（エルフ・猪・狂戦士・剣聖・炎術師・砲台）と、隣の道具（槍0.25・魔剣0.3）の合計で、上限100%。防御が高い相手ほど効く。
- **戦闘時間の目安は10秒**（アグロ7秒・ミッドレンジ10秒・ロングレンジ12秒〜）。回復・時間で効く効果は、ミッドレンジ以降で採用できる値段にする。
  - 回復の係数：0.05 → 0.025（回復1/秒 × 10秒 = HP10 = 実力0.025）。
- **道具**（10秒目安）
  - 道具の攻撃時の効果は「隣3体 × 攻撃速度1.2」を標準にする（itemOnHit 3 → 3.6）。毒瓶 3→4、魔剣 4→5、スタンガン 1→2 に上がる。
  - 毒の香炉は、毒瓶と同じ毒量（約2.9/秒）にする。ただし魔導シナジーの毒ボーナスは「付与1回ごと」なので、1秒に3ずつより、0.3秒ごとに1ずつの方が毒瓶に近い。
  - 防御を上げる全体効果は「3体ぶん」で数える（2体なら割高、ペンタグラムの4体ならお得）。結界石は 2→1 前後。
  - 呪いの人形は「2秒ごとに2秒の呪い」。呪いは重ならないので、呪詛師と併用すると価値が落ちる点に注意。ずっと呪い（受けるダメージ+25%）がコスト2前後になるので、強すぎないかを試算で確かめる。

## ペンタグラムと3行のボードの間の麻痺（直す候補）

攻撃は計算行の割合で分かれる（spec.md §2）。一方、攻撃時の効果（麻痺など）は分かれない。割合のいちばん大きい相手1体を「狙う相手」にして、そこに丸ごとかかる。同じ割合なら上の行が選ばれる（`src/engine/battle.js` の攻撃の解決と `pickParalyzeTargets`）。毒と呪いはチーム全体にかかるので、影響を受けるのは麻痺だけ。

- **ペンタグラムが3行のボードを麻痺させるとき**：1行目と2行目は相手の1行目、3行目は相手の2行目、4行目は相手の3行目を狙う。
  - 2行目は相手の2行目を、3行目は相手の3行目を狙わない。
- **3行のボードがペンタグラムを麻痺させるとき**：1行目はペンタグラムの1行目（1体）、2行目はペンタグラムの2行目（5体）、3行目はペンタグラムの4行目（1体）を狙う。
  - **ペンタグラムの3行目（5体）は狙われない**。かかるのは「ランダム」「全員」の麻痺だけ。
  - 3行のボードの電磁塔（行まとめて麻痺）は、1行目か3行目に置くと1体にしかかからない。
- このため、麻痺のやり取りはペンタグラムがかなり有利。Ver.2 の上位にペンタグラムの機械（電磁塔）が来る理由の一つかもしれない。
- 直し方の候補：
  - 麻痺も割合で分ける（例：割合0.5の行それぞれに、半分の秒数をかける）
  - 同じ割合なら、上の行と下の行を交互に狙う
- 定期付与（毒・呪い）の狙いは、いつも相手の計算行1の前線。いまは全体にかかる効果だけなので問題ない。将来、定期付与の麻痺を足すなら同じ点に気をつける。

## Ver.2 の答え（2026-11-06、40分×3回＋まとめ＋延長40分）

結果は `tools/search-out/v2-final2/`（チーム・一覧.txt・レポート.html・analysis.json）。どのチームも均衡に対して 0.51 以下。均衡だけを相手にボードごとに探しても、ペンタグラム 0.50・スクエア 0.50・ハニカム 0.34。

- 型は4つ。A ペンタグラムの電磁塔＋毒（35%）、C ペンタグラムの偵察機・鷹の麻痺速攻（32%）、D スクエアの魔人・預言者の混成（21%）、B ペンタグラムの鷹・預言者の速攻（12%）。相性は A > D > B > A の3すくみで、C は中間。
- ペンタグラムが79%、ハニカムは0%。ハニカムの最強は A・C（麻痺の機械）に 3〜7 で負ける。
- 52個の駒のうち33個が均衡で使われない。コスト9以上は魔人だけ。戦士は見習い剣士以外の全部。
- 遺物で使われないもの：砂時計・戦の角笛・獣のトーテム・癒しの泉・孤高の紋章・解毒の聖水。
- よく使われる遺物は 砥石・方陣の旗・歯車の心臓（全員への足し算）。「攻撃速度×足し算の強化」が強いという見立てと合う。
- 体の数に比例する得（遺物・全体強化・シナジーの段階・攻撃時の効果の回数）がペンタグラムに寄っている。コスト式だけなら3ボードの実力の合計はほぼ同じ（23.5 / 23.0 / 22.6）。

## Ver.2 の探索で見えていること（2026-11-05 時点）

- 上位はペンタグラムとスクエアだけ。**ハニカムのチームは、どの探索の均衡にも出てこない**。
