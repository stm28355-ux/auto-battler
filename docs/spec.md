# Auto Battler 仕様書

> 数値はすべて初期値。Phase 7（バランス調整）で見直す。
> 「（調整）」が付いた項目は特に変わる前提。

## 1. 概要

ボードに駒（キャラクター・道具）を配置し、遺物を最大3つ持たせてチームを作る。
2チームが自動で戦い、プレイヤーは戦闘中に操作しない。

## 2. ボード

座標は `(行, 列)`。列が小さいほど前（敵側）。

| ボード | マス数 | コスト上限 | マス |
|---|---|---|---|
| ペンタグラム | 12 | 10 | (1,3) (2,1)(2,2)(2,3)(2,4)(2,5) (3,1)(3,2)(3,3)(3,4)(3,5) (4,3) |
| スクエア | 9 | 12 | (1,1)(1,2)(1,3) (2,1)(2,2)(2,3) (3,1)(3,2)(3,3) |
| ハニカム | 7 | 14 | (1,2)(1,4) (2,1)(2,3)(2,5) (3,2)(3,4) |

### 隣接

- **スクエア**：上下左右の4方向。
- **ハニカム**：同じ行で列±2、または行±1かつ列±1。中央(2,3)は6マスと隣接する（意図的）。
- **ペンタグラム**：三角形の向きは次のとおり。
  - (1,3)=△
  - 2行目 = ▽△▽△▽
  - 3行目 = △▽△▽△
  - (4,3)=▽
  - 同じ行で列±1は隣接。
  - 縦の隣接は (1,3)-(2,3)、(2,2)-(3,2)、(2,4)-(3,4)、(3,3)-(4,3) の4組のみ。

### 前線

- 各行で、列がいちばん小さい**キャラクター**を、その行の前線とする（道具は前線にならない）。
- キャラクターのいない行には前線がない。
- キャラクターは必ず1体以上配置する。

## 3. 駒

### キャラクター

| 項目 | 範囲（初期） | 説明 |
|---|---|---|
| コスト | 自動計算 | §6 |
| HP | 100〜1000 | チームHPに加算される |
| 攻撃 | 10〜100 | |
| 防御 | 0〜100 | 前線として攻撃を受けるときに使う |
| 攻撃速度 | 0.5〜3.0 | 1秒あたりの攻撃回数 |
| 特殊効果 | 0〜2個 | §5 から選択 |
| 種族 | 1つ | §4 |

### 道具

| 項目 | 説明 |
|---|---|
| コスト | 自動計算 |
| 攻撃 | 隣接するキャラクターの攻撃に加算 |
| 防御 | 隣接するキャラクターの防御に加算 |
| 特殊効果 | 0〜2個 |

道具自身は攻撃しない。前線にもならない。
道具の「攻撃時」効果（毒・麻痺）は、隣接するキャラクターの攻撃に付与される。

### 遺物

- マスを使わず、コストもかからない。1チームにつき最大3つ。
- 特殊効果だけを持つ（例：チーム全体の攻撃+10%）。

## 4. 種族シナジー（調整）

同じ種族のキャラクターが2体以上／3体以上いると、チームにボーナスが付く。

| 種族 | 2体 | 3体 |
|---|---|---|
| 戦士 | 種族の防御+15 | 種族の防御+30 |
| 魔導 | 毒付与量+1 | 毒付与量+2 |
| 獣 | 種族の攻撃速度+15% | 種族の攻撃速度+30% |
| 機械 | チームHP+10% | チームHP+20% |

## 5. 特殊効果

各効果は「種類＋パラメータ」の組で表す。駒作成では一覧から選んでパラメータを入力する。

| 種類 | 発動 | パラメータ | 内容 |
|---|---|---|---|
| 毒 `poison` | 攻撃が当たったとき | `stacks`、`chance` | 相手チームに毒を `stacks` 付与する。0.1秒ごとに「蓄積量」ぶんダメージ。防御無視、戦闘終了まで続く、重ねがけで加算 |
| 麻痺 `paralyze` | 攻撃が当たったとき | `target`、`duration`(3s)、`chance` | 対象の攻撃速度を半減する。重ねがけで持続時間が延長される |
| 隣接攻撃倍率 `adjAtkMult` | 常時 | `mult`（例 0.2） | 隣接キャラクターの攻撃倍率を +mult |
| 回復 `heal` | 一定間隔 | `amount`、`interval` | 自チームHPを回復（最大HPを超えない） |
| ステータス強化 `statBuff` | 常時 | `stat`、`value`、`mode`、`scope`、`tribe`（任意） | 遺物・種族ボーナス向け。`mode` は `add`（加算）か `pct`（割合）。`tribe` を指定するとその種族だけに効く |
| 毒付与量 `poisonBonus` | 常時 | `value` | 種族ボーナス専用。毒の付与量に加算 |

**麻痺の `target`**（効果ごとに選ぶ）
- `front`：攻撃した相手の前線
- `random`：敵キャラからランダム
- `fastest`：攻撃速度が最も高い敵
- `strongest`：攻撃が最も高い敵

ランダム要素はすべてシード付き乱数を使い、同じ入力からは必ず同じ結果が出るようにする。

## 6. コスト計算（調整）

```
キャラ = ceil( HP/400 + 攻撃×攻撃速度/40 + 防御/50 + Σ効果コスト )   最低1
道具   = ceil( 攻撃/20 + 防御/25 + Σ効果コスト )                     最低1
```

効果コスト（初期値）：

| 効果 | コスト |
|---|---|
| 毒 | 0.5×stacks×chance |
| 麻痺 | 1.0×chance |
| 隣接攻撃倍率 | 5×mult |
| 回復 | amount/interval/10 |

## 7. 戦闘

### チームHP

- 最大HP = 全キャラクターのHPの合計（＋ボーナス）。
- キャラクターは個別には倒れない。

### 進行

- 0.05秒刻みの固定ステップで、最大30秒（600ステップ）進める。
- 各キャラクターは `1/攻撃速度` 秒ごとに攻撃する。麻痺中は攻撃速度が半分になる。
- 同じステップ内のダメージ・回復は、両チームぶんを集計してから同時に適用する（先攻・後攻の有利をなくすため）。

### 攻撃

- **対象**：攻撃者と同じ行にいる敵の前線。その行に前線がいなければ、いちばん近い行の前線を狙う（同じ距離なら行番号が小さい方）。
- **ダメージ** = `攻撃(実効) × 攻撃倍率 × 100 / (100 + 対象の防御(実効))`
  - 攻撃(実効) = 基本値 + 隣接道具の攻撃 + 種族・遺物などのボーナス
  - 防御(実効) = 基本値 + 隣接道具の防御 + 種族・遺物などのボーナス
- **毒**：0.1秒ごとに、相手チームHPから蓄積量ぶん減らす。

### 勝敗

1. 片方のHPが0以下になった時点で、そのチームの負け。
2. 同じステップで両チームとも0以下になった場合は、`HP/最大HP`（負の値になる＝はみ出した割合）が高い方の勝ち。
3. 30秒経過時は、`HP/最大HP` が高い方の勝ち。
4. 2・3で値が完全に同じなら引き分け。

### バランス目標

- 平均的な対戦が約10秒で決着する。
- 特定の駒・ボードの勝率が突出しない。

## 8. ゲームモード

| モード | 内容 |
|---|---|
| 駒作成 | オリジナルのキャラ・道具を作成・保存。チーム編成で使用可。JSON入出力 |
| チーム編成 | ボード選択・配置・遺物。9スロット保存。JSON入出力 |
| カスタム対戦 | 両チームを自分で選んで対戦 |
| ランダムマッチ | 自チーム vs ゲーム側のプリセットチーム |
| ストーリー | バランス調整後に設計 |
| ローグライト | バランス調整後に設計 |

## 9. 保存とJSON

- 保存先は localStorage。
- 入出力は、ファイルのダウンロード／読み込みとクリップボードの両方に対応する。
- 読み込み時に形式チェックを行い、不正なJSONは理由を表示して拒否する。

```json
// 駒
{ "format": "auto-battler/piece", "version": 1,
  "piece": { "id": "u_xxx", "kind": "character", "name": "見習い剣士", "icon": "🗡️",
    "hp": 300, "atk": 40, "def": 30, "spd": 1.0, "tribe": "warrior",
    "effects": [ { "type": "poison", "stacks": 1, "chance": 0.5 } ],
    "sprite": null } }

// チーム
{ "format": "auto-battler/team", "version": 1,
  "team": { "name": "チームA", "board": "square",
    "slots": [ { "pos": [1,1], "pieceId": "c_swordsman" } ],
    "relics": ["r_whetstone"],
    "customPieces": [ ] } }
```

- チームJSONには、使用している自作駒の定義を `customPieces` として同梱する。他人のチームを取り込んでも動くようにするため。
- `sprite` は将来のドット絵用（§10）。
